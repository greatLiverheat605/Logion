# 用户画像系统

## 概述

Logion 提供 4 类预设用户画像，根据学习场景优化应用导航：

- **考（📝）**：应试学习，突出考试、复习和学习记录。
- **学（📚）**：自主学习，突出每日目标、记录、规划和模板。
- **研（🔬）**：学术研究，突出知识管理、复习、规划和模板。
- **导（👥）**：团队协作，突出空间、审计、规划和模板。

用户也可以创建自定义画像，自由组合 12 个应用入口。每日、设置、个人和帮助是自定义画像的必需入口。

## 技术实现

- **通用设置基础设施**：`UserSetting` 使用 `(user_id, key)` 复合主键，值最大 8192 字符，并通过整数版本执行乐观并发控制。
- **存储格式**：画像使用 key `persona`；value 是包含 `activePersonaId` 和 `customPersonas` 的 JSON 字符串。
- **API**：读取和写入复用 `/api/v1/users/me/settings` 的 GET/PUT。PUT 要求登录 Cookie、可信 Origin、CSRF 和用户级限流；普通偏好保存不要求近期重新认证。
- **前端状态**：`PersonaProvider` 载入当前画像并提供切换、创建、删除和路由可见性判断。
- **软守卫**：侧边栏、移动导航和命令面板只显示当前画像的入口；直接 URL 访问不被画像阻止，真正权限仍由后端工作区规则决定。
- **每日入口**：每日工作台顶部根据当前画像展示 3 个优先入口，并提供快速画像切换；下方继续使用同一套真实执行数据，不展示原型中的虚构统计值。
- **入门引导**：首次登录且不存在 `onboarding_completed: "true"` 时进入 `/onboarding`；第 1 步必须选择画像。

画像是个人 UI 偏好，不等于 `WorkspaceMembership.role`，也不能授予或撤销任何工作区权限。

## 自定义画像

在 `/app/settings` 中：

1. 选择「新建自定义画像」。
2. 输入名称、说明并选择图标。
3. 勾选需要显示的功能入口。
4. 保存后切换使用；自定义 ID 自动生成，格式为 `custom-<uuid>`。

自定义画像会随 UserSetting 同步。若删除当前画像，前端自动回退到「学」。
