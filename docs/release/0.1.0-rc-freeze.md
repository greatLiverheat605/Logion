## 1. 冻结含义

本记录冻结的是 0.1.0 发布候选的运行时代码与契约，不等同于已经批准生产上线。从本记录建立起，PR #186 只接受以下变更：

- 发布阻断缺陷修复；
- 测试、CI 或生产安全门禁修复；
- 与真实实现一致的用户、部署和恢复文档修正；
- 不改变运行时行为的格式或可复现构建修正。

不再向 0.1.0 候选加入新页面、新业务能力、新路由、新数据模型或新的第三方平台集成。新功能进入后续版本评审。

## 2. 冻结范围

- Next.js Web/PWA 和 16 个受保护功能路由；
- FastAPI 身份、Workspace、学习、研究、协作、AI、同步、导入导出与审计接口；
- PostgreSQL 迁移链，当前 head 为 `0034_sync_conflicts`；
- IndexedDB、加密 Vault、Outbox、Bootstrap、Yjs 与冲突处理；
- PostgreSQL、Redis、附件、加密备份和四个不可变应用镜像的 Compose 边界；
- OpenAPI 与同步契约快照。

## 4. 生产上线阻断项

以下项目不属于仓库单元测试可以代替的外部环境配置。任何一项未完成时，只能保持封闭测试状态：

1. 生产域名、备案、DNS、HTTPS、自动续期和 HSTS 验收；
2. 阿里云邮件推送适配器及邮箱验证、邀请、找回密码真实投递验收；
3. 私有 OSS 异地加密备份、ECS RAM 角色和独立恢复演练；
4. 健康、5xx、OOM、磁盘、备份和证书到期告警送达真实接收人；
5. HTTPS 域名下的登录、快速刷新、双设备同步、离线恢复和冲突处理；
6. 至少一台实体 iPhone/iOS Safari 和一台 Android/Chrome 的软键盘、触控、弱网及 PWA 验收。

## 5. 手机端边界

0.1.0 已实现响应式 Web、移动底部导航、移动浏览器自动化检查和可安装 PWA Manifest，但不是原生手机应用。当前 Service Worker 只提供公共离线兜底，不支持受保护工作台完整离线冷启动；实体手机验收仍是生产门禁。

## 6. 数据与容量边界

- PostgreSQL、Redis、附件和本机备份默认位于 Docker 数据卷；单机磁盘损坏会同时影响这些副本。
- 数据库必须使用块存储，不得放在 OSS、对象存储挂载或同步盘上。
- 附件当前使用文件系统存储；迁移到 OSS 需要单独实现并测试存储适配器。
- 加密备份可以在不改变应用契约的情况下复制到私有 OSS，并通过生命周期策略转入低频或归档层。
- 2 核 2 GB 只适用于低频封闭使用；持续低于 200 MiB 可用内存、Swap 超过 1 GiB 或任何 OOM 都要求停止扩员并升级内存。

## 7. 清理与回滚

新候选上线后至少观察 24 小时。登录、刷新、核心写入、同步、备份、恢复和告警全部通过前，不删除旧源码、旧镜像或部署前备份。任何时候都不得删除 PostgreSQL、Redis、附件或备份数据卷来解决发布问题。

实际发布和清理步骤以 [`../../infra/runbooks/aliyun-production-release.md`](../../infra/runbooks/aliyun-production-release.md) 为准。
