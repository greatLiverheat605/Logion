# 功能总览

默认关闭的 v0.3 研究预览使用独立在线外壳与服务器偏好，入口和开关见
[研究工作台合同](../development/research-workbench.md)。旧版工作台继续保留。

预览的 `/library` 已支持个人文献增删改查、阅读状态／标签筛选及标识符去重；
`/read/[id]` 展示文献信息，正文等阅读功能仍为后续阶段占位。
研究 API 另提供私人想法 CRUD、AI 上下文隐私检查和七类任务路由预设，
想法界面与具体阅读 AI 交互在后续阶段提供。

预览的 `/settings` 支持本人配置、测试和撤销 Zotero 只读 Key 与坚果云应用密码，
仅返回连接状态、最近同步时间和错误码；配置说明见[文献集成](../operations/research-integrations.md)。

新版 `/search` 与 ⌘/Ctrl+K 共享当前空间搜索，覆盖本人文献、全文、摘录，以及可读知识点和回忆题；命中可返回原文页或复习。没有想法、连线或答案检索（ADR-0058）。

新版 `/settings/security` 提供有效会话设备列表、确认撤销与退出其他会话。正常退出保留设备识别；后台撤销超过 30 天没有有效会话的设备并保留历史（ADR-0056）。

新版设置下的 `/settings/ai` 复用服务端凭据边界，支持连接测试、模型能力与价格、研究经济／高质量预设、主备路由与预算；`/settings/audit` 提供账户／工作区审计分页和筛选。

文献库支持多 PDF／文件夹导入到坚果云，原文按本人权限读取，加密缓存按最近使用淘汰，设置页显示月流量提示。

Zotero 可手动同步到当前空间，之后每 30 分钟增量更新元数据、集合标签和文字批注。
远端删除只归档文献；私人摘录不会经旧共享知识接口公开。

本页按当前 Web 应用的 21 个业务页面组织功能。详细步骤见[用户操作手册](../user-guide.md)，内部路由合同见[架构说明](../architecture/route-function-contract.md)。

画像控制入口的显示顺序与可见性，工作区角色和空间权限决定实际操作权限。未显示的页面可在有权限时通过直接地址访问。

## 公共流程

登录、注册、邮箱验证、密码恢复、邀请确认、只读分享和首次使用引导分别有独立页面。生产注册遵守部署策略；邀请存在不代表任何人都可加入。

工作区邀请在同一事务中加密进入邮件队列；Worker 在投递前复核邀请、邀请人和工作区状态，终态清除密文。实际送达依赖邮件服务，手动复制邀请链接仍可用。

应用会尝试自动续期；会话无法恢复时提供重新登录入口。正常完成登录后返回原页面路径，账户删除状态和首次使用引导优先；同一标签页内，今日、规划、记录、复习、备考、模板、自学、研究和协作页恢复上次的工作区与空间，搜索页恢复工作区，复习页另恢复标签与选中知识点，退出登录时清除；不保证恢复未提交草稿。导出下载仍单独检查文件有效期与近期认证。

## 数据与权限

- Workspace 表示协作组织边界，Space 决定具体内容的可见范围。
- Private Space 正文只对所有者开放；工作区管理角色不自动获得读取权。
- 私有资料转为共享或发送到 Provider 都需要明确选择。
- 已同步、已上传、已验收、已批准草稿分别表示不同结果。

## 条件可用与未提供的能力

| 能力                 | 当前边界                                                                    |
| -------------------- | --------------------------------------------------------------------------- |
| 离线                 | 支持既有离线实体和加密队列；受保护页面不保证完整冷启动                      |
| 新知识空间接口       | 默认开关、共享写入、AI 接受、删除和本地 Worker 分别控制；不自动进入 sync-v1 |
| AI                   | 必须配置 Provider；批准草稿不自动覆盖正式对象                               |
| 邮件、附件扫描与备份 | 需要部署者接入、配置和独立验证                                              |
| 移动端               | Web/PWA 与薄壳源码已有；签名、真机和发布需单独验收                          |
| 第三方连接与自动化   | 尚未提供通用账号连接、Webhook、MCP/API Token 或自动化规则                   |

服务的健康状态和功能准入由具体部署负责；源码中存在接口不代表任意环境已经启用。

## 表单、审计与当前删除边界

任务支持提交终验、5–480 分钟范围提示和失败草稿保留；考试支持日期与分数成对校验。规划、任务和搜索显示统一本地资料锁定提示；模板产物通过既有增量同步进入规划。工作区管理员可切换审计范围查看业务事件，设备支持确认后批量撤销其他会话。

手动创建目标时先建立首个阶段；部署开启阶段编辑（`LOGION_PLANNING_PHASE_REVISION_ENABLED`，默认关闭）后，可对已有目标追加、修改、重排、归档阶段，被任务引用的阶段只能归档。收件箱分诊在建立路线/项目成功时原子移出原条目，并支持确认删除；考试支持整组软删除，未关联学习记录或引用的知识点支持确认删除；知识点可编辑名称与说明，先修关系可删除，回忆题可编辑（有作答后判定方式锁定）或停用并保留作答历史（ADR-0036）。应用内共享本次 Vault 解锁状态，从成功解锁起 30 分钟到期；手动锁定、退出或刷新后也需重新解锁。已加密保存内容保留。新建目标的背景说明与验收标准、周期审查总结、回忆题解析和研究声明会在 Vault 解锁时加密保存为本机草稿（ADR-0034），刷新或重新登录后解锁再打开同一表单时询问“恢复未提交内容？”；提交、丢弃、退出登录或 7 天后删除，不同步；其他表单的未提交输入不保证恢复。快速捕获支持保存后继续或关闭，明确区分本地保存与服务器同步。旧模板缓存缺失可通过规划页“补全服务器资料”恢复。

## 笔记与复习闭环

记录页可将正文或安全预览选段经确认创建为知识点或自评题目，沿用当前空间、加密离线队列及同步依赖；来源标题和原文作为说明保存；开启 `LOGION_SOURCE_LINKS_ENABLED` 后另建只含 ID、偏移与摘要哈希的来源链接，复习页显示来源状态并可回到原选段，记录页列出由此创建的对象（ADR-0033）。前往复习时保留工作区和空间选择。

同步推送、非空拉取和成功冲突处理的数量回执进入通知历史，重复请求去重，不包含内容。Worker 按通知偏好、用户时区和安静时间产生每日到期复习汇总，每工作区每天最多一条；完成、跳过、进行中、删除或撤权的计划不触发。通知链接进入对应工作区的复习或同步页，日历继续提供有效复习计划投影。均不发送邮件或第三方推送。

通知中心读取当前工作区最近 200 条记录，普通成功的推送和拉取回执分别折叠，原条目可展开并逐条标为已读；异常与冲突处理回执独立显示。搜索遵循页面的 2–100 长度限制；清除查询保留筛选，清除筛选同时重置查询。读取失败保留当前工作区已确认的数据，并显示错误供重试。

研究 PDF 阅读器支持连续滚动、文字层、大纲、缩略图、查找、缩放和随主题变化的纸面；全文按文件 SHA 在线保存，仅本人可用。

阅读器选区动作提供 T 翻译、E 解释、Q 引用提问、H 摘录和 C 关联私人概念，复用研究 AI 路由与草稿边界；手机可在结果栏查看和提问。

- 研究精读笔记：阅读器七节 Markdown 模板、Yjs 在线自动保存、缺失章节 AI 草稿、本人原子接受与版本冲突保护；私人归属不进入旧共享与离线链路。
- 研究理解测验：每篇文献 AI 起草 5 题、本人接受、手机作答、AI 批改证据、按需查看参考答案；本人确认掌握才进入阅读复习，支持到期筛选、回到原文及后续修正。

- **阅读状态与今日**：本人开始／完成／重新阅读，服务端记录精读完成时间；当前空间的今日页显示可分页的私人在读列表，文献库按状态筛选。沿用默认关闭的研究开关，无离线队列或新迁移。
- **研究问题与想法**：`/questions` 在线问题树支持状态、调整上级、拆分和保留原记录的合并；私人想法分开查看、编辑和归档，AI 与 agent 不可读取。旧研究问题继续可用，跨本人／空间父子关系被拒绝。
- **私人连线 API**：固定方向和关系词表，手动连线直接确认，AI 仅建议；本人以版本校验确认或拒绝，被拒绝边永久去重。共享空间成员也不能读写他人的连线，想法及其邻接关系不进入 AI。
- **阅读局部图**：阅读栏可选当前文献的两跳知识网；自测预设为 PDF／测验／局部图，手机先显示测验，旧布局继续可用。
- **知识网画布**：按问题聚焦，节点和连线可键盘选择；实线／虚线区分本人确认和 AI 建议，想法仅手动连线。窄屏文字列表、双主题、200 节点／400 关系上限；原有概念先修只读显示。

### 私人周阅读计划与回顾

研究工作台 `/plan` 复用目标和 Task，支持私人周任务、本人完成确认、统计快照和逐项处理未完成项。周回顾确认后生成下周计划，旧周保留；AI 仅接收固定数字统计，点评必须本人接受。新任务不进入旧同步、共享搜索或旧格式导出。依据 ADR-0044、ADR-0052。

目标列表在线显示原有目标与阶段。启用阶段修订开关后，可编辑标题、说明、期望成果、每周分钟数和日期；阶段支持键盘排序、归档、恢复和受引用保护的明确移除。新增在线写入与旧同步日志同事务，过期版本保留输入并提示重新载入。今日页按本机日期汇总到期复习与私人阅读计划。依据 ADR-0053。

### 在线记录与旧笔记

`/records` 分页列出当前空间的普通笔记和本人的私人精读笔记，按需加载正文。普通笔记在线使用 Yjs 增量自动保存，标题乐观编辑不重置文档；业务与旧同步日志同事务，旧客户端可继续收到更新。共享写入权限不变，精读笔记通过阅读器编辑；来源不可用时保留正文查阅。失败保留输入并显式重试，不使用本机离线存储。依据 ADR-0054。

### 统一在线复习

`/review` 统一展示旧知识点、回忆题及私人阅读测验。普通内容在线新建、纠错、先修关系、作答、自评与本人掌握确认复用原调度服务；原同步游标可读取同事务变更。题目可定位已有笔记选段或进入阅读器；危险操作在“更多”菜单中预检并确认，停用题目保留学习历史。手机可完成作答；不使用离线存储。依据 ADR-0055。

### 研究数据导出

`/settings/data` 支持 v0.3 与旧格式独立创建／列表／取消／下载；研究格式明确包含本人
私人想法、阅读全文、摘录、精读笔记、测验和批改、连线及周回顾。复用加密后台产物及
24 小时到期，生成与下载均复核当前空间权限；研究默认关旗、无新迁移或离线存储。
旧路径及格式保持兼容，研究格式暂不提供导入。依据 ADR-0057。
