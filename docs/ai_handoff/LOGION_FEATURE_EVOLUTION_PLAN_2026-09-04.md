> 规划人：FABLE5-1 · 2026-09-05（自主提议）
> 基准代码：main @ 37e2e00

## 0. 说明

本文档为自主提议，与 RC8 审计台账（修 bug）互补。
**定位：个人与小规模自用（≤10 用户），保留协作，不做商业化，注册为邀请制。**
每条提议先过一遍判据：「这个功能是让"我自己和少数几个人"用得更好，还是让"产品更好卖"？」后者一律排除。

证据等级标注：

- `[实测]` 有审计或 GPT5.6 黑盒证据
- `[代码]` 本轮读源码确认（视同实测，但只证明"代码里是这样"，不证明线上行为）
- `[推断]` 从代码结构合理推断，未验证
- `[提议]` 自主设计，无既有依据

**本文档任何内容不进入 v0.2.1。** v0.2.1 只修 P0/P1（+可选 P2），见 `LOGION_V021_MAINLINE_PLAN_2026-09-04.md`。

量级：S ≤ 1 天；M 2-4 天；L 1-2 周；XL 需拆分。

## 3. 明确不做的方向（及理由）

| 方向                                                                        | 为什么不做                                                                                             |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 定价、计费、套餐、权益（entitlement）体系、支付回调                         | 不商业化。代码里几乎没有商业 UI（memory 记录），约束文档 §19 的 SaaS 段落是待作废内容                  |
| 面向大规模的多租户改造（分库、租户级限流、Operator 控制面扩展）             | ≤10 用户。现有 `workspace_id` 隔离已足够（审计 Invariant 3 ✅）。Operator 控制面只保留最小 break-glass |
| 公开营销站、SEO、Open Graph、sitemap                                        | 注册邀请制，没有"被搜到"的需求                                                                         |
| 竞品对标驱动的功能（Notion 式数据库、Anki 全部卡片类型、Obsidian 全部插件） | 判据第二类。只做闭环上缺的那一环                                                                       |
| 公共模板市场、模板审核与举报                                                | 模板功能保留（已建成），但只在 Workspace 内共享；不做公开发布                                          |
| 应用商店分发（apps/mobile 薄壳）                                            | ADR 0028 的薄壳可作侧载/个人签名安装（`mobile-ios-personal-team.md`）；不投入商店审核与合规            |
| 增长分析、行为埋点                                                          | 无运营需求。保留安全审计（约束 §9），不加产品分析                                                      |
| Postgres 全文检索 / 外部搜索服务                                            | 万级对象下 ILIKE 够用；中文 FTS 分词成本高；外部服务违反约束 §18.1 "不将敏感正文发送第三方"            |
| 实时协同编辑（多人同时编辑同一 Note）                                       | ADR 0026 明确"实时协同编辑不在范围内"；Yjs 只用于离线合并                                              |
| AI 自动应用（AI 直接改正式数据、自动完成任务、自动更新掌握度）              | 违反 Invariant 5。所有 AI 输出停在草稿                                                                 |
| 第三方连接器平台（Zapier/IFTTT、通用 webhook 市场）                         | 互操作 hub 已有 iCal feed 与导出；平台化是"更好卖"方向                                                 |
| 论文全文托管、绕过付费墙                                                    | 约束 §17.3 CourseIndex 只存索引；研究域同理                                                            |
