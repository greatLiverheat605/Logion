# Logion D2：完整交互原型规格

> 对应原型：`prototype/logion-redesign-v1/d2-approved.html`
>
> 数据：全部为合成数据；不访问真实账户、API、邮件或生产环境。

## 1. 工作区结构

桌面统一使用：

```text
240px 可折叠侧栏 | 44px 上下文栏 | 主工作区 | 可控 Inspector
```

侧栏只展示五个任务区域：今天、工作台、知识库、协作空间、系统中心。旧 URL 不删除，通过命令面板、面包屑和直达链接进入新的可见区域。移动端使用 Today、工作台、知识库、协作空间、系统中心五个底部入口，页面内容纵向堆叠，不能把桌面三栏硬压缩成不可读的小列。

## 2. 页面模板

### Today

- 标题区：今天 + 一行说明 + 调整计划/开始当前行动；
- 主行动：研究缺口、计时、归属、Why、Evidence、完成后的下一步；
- 有限队列：最多显示三项，分别标记复习、资料、研究；
- 完成操作只产生会话或证据草稿，不能直接接受正式结论。

### Workbench

- 学习：路线、掌握、复习和成果；
- 研究：Source → Excerpt → Claim → Evidence → Finding → Output；
- 考试：大纲、薄弱项和模拟记录；
- 导师：Rubric、反馈和学员进度；
- 自定义：受控模块、顺序、筛选、默认视图和有限属性。

所有模板共享对象、权限、同步、AI Draft 和人工验收合同，只改变默认布局和筛选。

### Knowledge Base

- Sources：来源列表 + 阅读器 + 来源版本；
- Topics：主题、掌握度和复习队列；
- Graph：有界 1/2 跳局部图，正式边实线，候选/探索边虚线；
- Review：知识对象的复习任务；
- History：证据、决定和版本历史；
- Inspector：来源、摘录、关系、状态、历史和回源动作。

桌面图谱提供缩放、平移、选择、方向键和 Inspector；移动端使用同一节点集合的列表/树和详情堆叠。

### Research

三栏为 Source 列表、Claim 编辑器、Evidence Inspector；在窄屏纵向堆叠，来源仍可选择，Inspector 可折叠。AI 只提供候选声明或候选证据，不显示假成功。

### Collaboration

Workspace 负责成员与协作；Space 负责知识库数据边界。邀请表单展示角色、pending、重复成员和 409 恢复动作。重复邀请不发送真实邮件。

### System Center

设置使用“分组列表 + 详情”而不是每项一个卡片。危险区独立展示最近认证、影响范围、确认和恢复。敏感能力展示“未开放/仅在线”，不提供假操作。

## 3. 全局状态

每个页面必须可呈现：`loading`、`empty`、`ready`、`pending`、`success`、`offline`、`locked`、`permission denied`、`409 conflict`、`capability disabled`、`error`。状态就地显示原因、请求编号和下一步恢复动作；pending 禁止重复提交。

原型控制条提供五种合成状态：就绪、离线、409 冲突、能力关闭、错误。正式施工要把它们映射到真实 API/SessionBoundary 状态，不复制演示文案或 `REQ-D2-042`。

## 4. 关键交互合同

- `Ctrl/Cmd+K` 打开命令面板，搜索对象、命令和旧路由；Escape 关闭并恢复焦点；
- 图谱节点单击选择，Enter/Space 等价于进入对象，方向键移动焦点，选中节点同步 Inspector；
- `1 跳 / 2 跳` 是明确的范围控制；节点上限 150、边上限 400，截断必须清楚显示；
- 任何保存、同步、邀请、接受、删除和撤销都经过本地校验、pending、成功/409/错误反馈；
- 邀请 409 要说明“已是成员/已有邀请/版本变化”以及比较、关闭或调整角色的动作；
- 危险操作要求二次确认、最近认证提示、影响范围和恢复路径；
- Light/Dark、舒适/紧凑和 Inspector 开关是可恢复的界面状态，不存储敏感正文或 AI 输入。
