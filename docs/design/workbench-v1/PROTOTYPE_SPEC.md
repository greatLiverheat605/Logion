# Workbench v1 隔离原型规格

> 状态：已完成浏览器复审并纳入产品 Owner 批准的 Workbench v1 基线
>
> 产品依据：[`WORKBENCH_V1_PRODUCT_SPEC.md`](../../product/WORKBENCH_V1_PRODUCT_SPEC.md)
>
> 原型不请求 API、不发送邮件、不写服务端、不改变生产开关。

## 1. 原型要证明什么

1. 四个固定工作台由不同对象和任务路径驱动，不是换色或调整卡片顺序；
2. Today 仍只有一套，并能混合展示不同工作台的行动来源；
3. 自定义工作台能组合已注册模块，但不能改变权限、正式对象或系统反馈；
4. 同一对象可以被多个工作台引用而不复制；
5. 五区 Shell、Context Bar、Inspector、Light/Dark 和移动体验保持统一；
6. 研究工作台可以有技术感，但技术感由证据、版本、关系和实验状态产生。

## 2. 原型形式

- 单个自包含 HTML，使用合成中文数据；
- 默认 1440px，提供 1024px、390px 和 320px 视口切换；
- Light/Dark、reduced-motion 和状态切换；
- 无 CDN、远程字体、真实账户、邮箱、Token、主机或私有数据；
- 不依赖正式 Web 组件，不代表迁移/API 已批准。

## 3. 稳定外壳

```text
┌──────────────┬────────────────────────────────────┬────────────────┐
│ 五区导航     │ 44px Context Bar + 主工作表面       │ Inspector      │
│              │                                    │                │
│ 今天         │ 当前工作台切换器                    │ 来源           │
│ 工作台       │ 领域对象与行动                      │ 关系           │
│ 知识库       │                                    │ 状态           │
│ 协作空间     │                                    │ 历史           │
│ 系统中心     │                                    │ 操作           │
└──────────────┴────────────────────────────────────┴────────────────┘
```

主品牌只使用矿物青绿交互色；成功、警告、危险、权限、正式/候选继续使用统一语义和文字标签。

## 4. 页面和交互范围

### P1：统一 Today

- 一个 Now 行动，展示来源工作台；
- Why、Evidence、Acceptance、Next；
- 最多三个后续行动，可来自不同工作台；
- 切换工作台不重建 Today 数据；
- Inspector 可返回原始对象。

### P2：学习项目桌面

- 当前学习项目和下一里程碑；
- 目标 → 路线 → 项目 → 成果轨道；
- 最近成果和掌握确认；
- 到期复习进入统一 Today/Review；
- 选中成果打开来源/证据 Inspector。

### P3：研究证据实验台

- 当前 Research Question；
- 来源列表、Claim/Evidence 矩阵和 Experiment Run 轨迹；
- 正式/候选/争议关系有文字标签和线型差异；
- 选中证据链只高亮相关路径；
- DOI、ID、版本、方法和指标使用等宽信息样式；
- reduced-motion 关闭布局和路径过渡。

### P4：考试覆盖指挥台

- 真实考试名称和日期；
- 科目/大纲覆盖矩阵；
- 到期复习和薄弱项；
- 最近模考趋势显示样本和时间；
- “安排模考”“开始复习”进入明确路径，不展示预测分数。

### P5：导师授权审阅台

- 顶部持续显示 Shared Space 和当前 Workspace Role；
- 待审队列、Rubric、反馈和开放发现；
- 私有对象不进入统计；
- 权限不足时不显示成员/对象存在性；
- 对比审阅和批注进入 Inspector，不使用成员排名。

### P6：自定义工作台创建器

- 复制固定模板/空白创建；
- 名称、图标、受控辅助色；
- 注册模块的显示、顺序和有限尺寸；
- 默认 Knowledge Base、视图和筛选；
- 有限属性示例；
- 桌面/移动预览；
- 保存前显示“不会复制对象、不会改变权限”；
- 删除工作台只删除配置和引用的影响预览。
- 名称和所有自定义文本按不可信输入转义；原型与正式实现均不得解释为 HTML。

### P7：对象引用语义

- 一个 Source 同时出现在学习和研究工作台；
- “添加到其他工作台”只增加引用；
- “从当前工作台移除”不删除正式对象；
- “删除正式对象”使用独立高风险确认并展示可见引用影响；
- 跨 Knowledge Base 操作明确进入 Space 授权路径。

## 5. 视觉计划

### 5.1 统一 tokens

- 画布：石墨浅灰/柔和炭灰；
- 表面：白色/抬升深灰；
- 品牌：矿物青绿；
- 文字：主/次/三级；
- 圆角：4/6/8px，卡片不超过 8px；
- 中文：系统可读字体；数据：稳定等宽字体；
- 4px 间距网格，边框优先，阴影克制。

### 5.2 工作台签名

| 工作台 | 单一视觉签名             | 克制方式                     |
| ------ | ------------------------ | ---------------------------- |
| 学习   | 横向项目/成果轨道        | 不做课程营销卡和奖章墙       |
| 研究   | 可追溯证据路径与实验轨迹 | 不用霓虹、粒子和伪实时仪表盘 |
| 考试   | 大纲覆盖矩阵             | 不用红色焦虑主题和预测成绩   |
| 导师   | Rubric 对比审阅          | 不用成员排行和 CRM 销售看板  |
| 自定义 | 受控模块网格与预览       | 不提供自由 CSS/任意拖拽画布  |

### 5.3 技术感边界

研究工作台允许更高数据密度、局部网格、等宽标识、细线关系和 300–600ms 有意义的布局收敛。技术感只存在于研究工作表面和知识图谱，不扩散到登录、设置、邀请和危险确认。

## 6. 响应式

- 1440：导航 + 主区 + 常驻 Inspector；
- 1024：导航缩窄，Inspector 覆盖或可关闭；
- 390/320：底部五区入口，工作台切换使用 Sheet，Inspector 全高 Sheet；
- 移动研究图谱提供等价列表/树；
- 所有按钮和输入触控目标至少 44px，正文无横向溢出。

## 7. 状态矩阵

全局状态控制至少覆盖：ready、loading、empty、saving、success、error、offline、locked、permission denied、409 conflict、disabled capability、stale data、AI Draft、graph truncated。

- 状态必须落到受影响模块，而不是全部堆在页首；
- 错误展示请求编号和恢复动作；
- 成功结果持续存在于行、对象或历史，Toast 只是辅助确认；
- 409 显示本地/远端差异，不自动覆盖；
- disabled capability 说明进入条件，不显示可提交的假按钮。

## 8. 键盘与无障碍

- 工作台切换器采用可访问 Tabs/菜单语义；
- Escape、焦点陷阱、关闭后焦点返回；
- 图谱 Enter/Space、方向键和等价列表；
- 可见焦点、读屏名称、状态 live region；
- 不仅依赖颜色区分工作台、关系和状态；
- Light/Dark 均执行对比度和 axe 检查。

## 9. 审批走查

1. 从 Today 打开研究行动并返回；
2. 依次切换四个固定工作台，确认对象和任务路径不同；
3. 在研究工作台核对一条证据链和实验运行；
4. 在考试工作台从覆盖缺口进入复习；
5. 在导师工作台验证 Shared/Private 边界；
6. 从研究模板创建自定义工作台并调整模块；
7. 把同一 Source 添加到学习工作台，确认对象未复制；
8. 触发 409、离线、权限不足、能力关闭和删除影响；
9. 切换 Light/Dark、reduced-motion、1024/390/320；
10. 产品 Owner 明确批准或列出修订意见。

## 10. 浏览器复审记录（2026-08-17）

- 静态门禁：Prettier、内联 JavaScript `node --check`、`git diff --check` 全部通过；最终 HTML 保持单文件自包含，临时 axe 审计标签已移除。
- 权限和对象边界：AI Draft 与正式摘录分离；`permission` 和 `locked` 下 Inspector 不返回对象详情；对象归属 Space 不随当前工作台变化；`disabled` 下引用入口不可提交。
- 交互闭环：桌面 Inspector 可关闭并扩展主区；移动 Inspector 使用模态语义、背景 inert、焦点陷阱、Escape 和焦点返回；对话框使用单一键盘处理器并在最终重绘后回焦。
- 领域等价视图：移动研究证据列表、考试覆盖列表和 Knowledge Graph 列表均可操作；桌面研究图和 Knowledge Graph 支持 roving tabindex、方向键、选中节点及相关路径高亮。
- 自定义工作台：名称、说明、图标、辅助色、默认知识库、默认视图、筛选、顺序、密度和注册模块可受控调整；不可信文本按文本渲染；保存真实经过 `saving → success receipt`；409 可比较并生成待保存的合并版本。
- 响应式：1440、1024、390、320px 的 `.page-scroll` 均满足 `scrollWidth === clientWidth`；移动触控入口至少 44px。
- 可访问性：使用仓库已安装的 `axe-core@4.12.1` 在真实浏览器执行 1440/390 × Light/Dark 四组 WCAG 2 A/AA 与 2.1 A/AA 审计，最终均为 0 violations。审计发现并修复了设备容器误带 `aria-pressed` 以及深色三级文字对比度不足的问题。
- 视觉复审：Light/Dark 均已截图检查；研究工作台的技术感来自证据路径、版本和实验轨迹，考试移动视图保持安静、可扫读，不引入第二套 Shell。

当前没有发现阻断产品审批的 P0/P1；仍需产品 Owner 明确批准视觉与产品语义后，才可进入正式施工任务包。

## 11. 停止条件

完成原型、浏览器验证和对抗复审后停止。没有产品 Owner 明确批准，不修改 `apps/web/src/**`、API、数据库、OpenAPI、迁移、生产配置或 Feature Flag。
