## 首次使用

### 1. 登录或接受邀请

已有账号可使用邮箱与密码，或受支持的 Passkey 登录。启用多因素认证后，按提示输入 TOTP 或一次性恢复码。

新成员按管理员提供的邀请流程完成注册与邮箱确认。生产环境的注册受邀请/关闭策略限制；无法自由注册时联系部署管理员。密码恢复依赖该环境实际配置的邮件服务。

### 2. 完成七步引导

新账号登录后先进入首次使用引导：

1. **画像**：选择考、学、研、导四种内置画像之一；自定义画像在完成引导后的设置中管理。
2. **工作区**：选择已有工作区，或在有权限时创建。
3. **空间**：选择已有空间，或创建默认仅自己可见的私有空间。
4. **口令**：设置并确认本机 Vault 口令。
5. **模板**：查看模板说明并跳过；完成引导后可到模板库选择和安装。
6. **目标**：设定今日目标。
7. **开始**：完成引导，进入今日页面。

完成后再次登录通常直接进入今日。画像只影响导航，不赋予新的管理或内容权限。

### 3. 理解工作区、空间和本机资料

| 概念                      | 作用                                       |
| ------------------------- | ------------------------------------------ |
| 工作区（Workspace）       | 组织成员、角色和协作范围                   |
| 私有空间（Private Space） | 个人内容，其他工作区成员不因此获得读取权   |
| 共享空间（Shared Space）  | 用于明确共享、共同审阅的内容               |
| Vault                     | 当前浏览器的加密本地资料，需要本机口令解锁 |
| Outbox                    | 等待同步到服务端的本地修改队列             |

进入页面后先确认当前工作区和空间。需要离线资料的页面若显示锁定，先解锁 Vault。账号密码用于登录，本机口令用于解锁资料，两者用途不同；重新设置账号密码不能替代原 Vault 口令。

## 日常学习闭环

### 创建目标和计划

入口：**计划**（`/app/planning`）。

1. 选择目标工作区与空间，解锁本地资料。
2. 创建目标，填写名称、可展示的成果、每周投入和目标日期。
3. 增加阶段，填写阶段成果、预计时间和验收标准。
4. 将阶段拆成可执行任务，按需要设置依赖与安排。
5. 保存，检查同步状态。

完成标志：目标、阶段和任务出现在对应列表。仍显示待同步时，记录尚未确认到达服务端。

### 执行任务并保留证据

入口：**今日**（`/app/today`）。

1. 查看今日任务、下一行动和阻塞情况。
2. 选择一次专注可以推进的任务，开始学习会话。
3. 结束会话时记录实际投入；遇到阻塞则记录原因。
4. 将文本、链接、笔记或资料作为成果证据提交。
5. 在证据与人工验收区域检查成果，明确提交验收决定和说明。
6. 根据实际结果调整任务状态和下一步安排。

完成标志：会话、证据和验收各自有记录。计时结束不等于任务完成，证据提交不等于验收通过。

## 笔记与资料

入口：**资料与笔记**（`/app/records`）。

### 创建笔记或登记资料

1. 选择空间并解锁 Vault。
2. 新建 Markdown 笔记，填写标题和正文。
3. 用标题、列表、引用和代码块组织内容，在预览中检查排版。
4. 网页资料保存为外部链接；PDF 可登记文件名、哈希、页码和定位说明。
5. 保存后，在任务或研究证据中引用相应记录。

Markdown 预览不会执行正文中的 HTML。PDF 定位元数据不代表 PDF 原件已上传，也不等于自动解析全文。

### 使用附件

在相应记录中选择文件后，查看附件队列状态。离线排队、等待上传、上传完成和校验通过是不同阶段。失败时查看原因，联网后按页面入口重试。

上传能力、文件大小、配额和扫描依赖由部署配置决定。不要因为文件已选中或已进入队列就删除本机唯一副本。

## 复习与备考

### 主动回忆与掌握度

入口：**复习与掌握**（`/app/review`）。

1. 建立知识点，按需要添加先修关系。
2. 为知识点创建主动回忆题。
3. 打开题目先作答，再查看参考内容或判定信息。
4. 记录作答结果、信心与错因。
5. 根据实际表现明确确认掌握等级，并安排复习。
6. 定期记录学习审查，调整阻塞和下一步行动。

完成标志：作答记录、掌握确认与复习安排分别保存。AI 建议和一次正确作答不会自动成为永久掌握结论。

### 备考流程

入口：**备考**（`/app/exam`）。

1. 创建考试，填写日期和目标分数。
2. 添加科目、权重与大纲节点。
3. 根据准备情况更新大纲覆盖状态。
4. 安排模考，完成后记录得分、满分和实际用时。
5. 结合成绩与薄弱项安排任务或复习。

没有成绩时图表显示空状态；大纲覆盖与考试分数分别记录，不能互相替代。

## 自学与研究

### 自主学习

入口：**自主学习**（`/app/self-study`）。

1. 将临时想法与资料放入收件箱。
2. 将需要长期推进的内容组织为学习路线。
3. 创建有明确交付物的项目，并拆分里程碑。
4. 推进任务，保存成果与证据摘要。
5. 回看路线和项目，决定继续、调整或结束。

### 研究

入口：**研究**（`/app/research`）。

1. 建立研究项目和具体问题。
2. 登记论文或来源资料，保留可复查定位。
3. 创建待验证的声明，分别关联支持、反驳和不确定证据。
4. 记录实验运行、指标与观察。
5. 根据证据明确更新结论，并保留局限和下一步验证。

声明、证据和确认结论是不同记录。引用存在或 AI 给出总结，都不代表结论已经成立。

## 工作区与小组协作

### 管理成员与空间

入口：**工作区**（`/app/workspaces`）、**空间**（`/app/spaces`）。

1. 确认当前工作区与本人角色。
2. 有相应权限时创建空间或成员邀请，选择必要的角色。
3. 检查邀请状态；过期或不再需要的邀请及时撤销。
4. 将确实需要协作的对象放入共享空间。
5. 变更成员角色、转让所有权或删除工作区前，阅读影响提示并按要求重新登录。

私有空间内容不会因为工作区存在 Owner/Admin 自动公开。最后一位 Owner 等保护条件仍由服务端检查。

### 共享审阅

入口：**导师与小组**（`/app/collaboration`）。

1. 选择可访问的共享空间。
2. 由有权限的成员配置 Rubric。
3. 创建审阅，明确选择共享对象。
4. 提交反馈与建议动作，再确认审阅结果。
5. 需要固定结论时生成报告快照。

完成标志：反馈和报告绑定明确共享的对象；个人笔记、错题和未提交草稿不自动进入报告。

## 模板与分享

入口：**模板与分享**（`/app/templates`）。

1. 选择模板，或从现有目标创建模板版本；也可导入受支持的模板包。
2. 检查内容、来源、许可与外部链接。
3. 选择目标空间并安装，得到独立副本。
4. 按实际需要修改安装后的对象。
5. 分享时仅选择必要字段、设置有效期，使用完毕后撤销。

更新模板不会静默覆盖已安装的个人记录。分享链接是访问能力，不应放在公开日志或无关群聊中。

## AI 工作台

入口：**AI 工作台**（`/app/ai`）。需要联网、相应权限和可用的 Provider。没有配置 AI 时，其他核心学习流程仍可使用。

### 配置连接、模型与预算

1. 在 Provider 区域填写服务名称、兼容服务地址和凭据。
2. 保存后明确触发连接测试与模型发现；该操作会访问外部服务。
3. 查看模型能力，启用需要使用的模型。
4. 创建任务路由，选择任务类型与模型顺序。
5. 设置输入/输出 Token 上限、重试策略与月度预算。

凭据保存在服务端加密存储中，页面不回显原密钥。配置界面中的管理权限不等于任意用户都能读取所有人的内容。

### 生成并审查草稿

1. 选择工作区、任务类型、目标与目标版本。
2. 明确填写发送字段、内容和期望输出，并核对来源范围。
3. 点击“预检发送范围与预算”。
4. 检查预检返回的 Provider、模型、发送范围与预算。修改表单后重新预检。
5. 确认后点击“确认并发送到 Provider”，等待运行结果。
6. 在草稿区阅读输出，需要时编辑草稿 JSON 并填写审查说明。
7. 点击“批准草稿”或“拒绝草稿”。

**批准草稿只保存人工审查决定，本工作台不会自动覆盖正式对象。** 新知识空间的正式接受事务还有独立的权限、版本检查和功能开关。

运行失败时先阅读状态与错误原因。若外部请求结果不确定，不要连续重复提交；手动重试可能产生新的外部调用和费用。

## 导入导出与日历

入口：**互操作中心**（`/app/integrations`）或 **数据**（`/app/data`）。部分画像可从设置或命令面板进入；入口未显示时可直接访问相应地址。

### 导入内容

1. 选择工作区，提交 Logion JSON、Markdown、CSV 或 BibTeX 等受支持内容。
2. 先查看导入预览，核对计数、格式和警告。
3. 选择本人的 Private Space。
4. 按页面要求输入 `IMPORT` 并确认。
5. 查看结果，核对导入后的记录。

预览成功不代表已经写入。导入后不能凭“已预览”判断是否还需要执行，也不要反复确认同一任务。

### 导出数据

1. 按提示重新登录，满足近期认证。
2. 核对导出范围，输入 `EXPORT` 创建任务。
3. 等待任务完成，下载有效期内的文件。
4. 保存页面的字节数、SHA-256 与 manifest 信息，按导出格式完成校验。
5. 妥善保存下载的 ZIP；其中包含明文导出内容，按需要在本机加密保管。

导出任务的服务端副本加密保存，下载接口解密后提供 ZIP，用户不需要服务器密钥。刷新页面或刷新会话令牌不一定满足近期认证；过期时应重新正常登录。下载链接有时效，导出也不能替代服务器备份恢复。

### 订阅日历

1. 创建 Calendar Feed。
2. 在一次性提示关闭前复制并保存订阅 URL。
3. 在日历软件中按 URL 订阅。
4. 不再使用或怀疑泄露时撤销 Feed。

旧 URL 撤销后立即失效。URL 丢失时不能重新查看，应撤销旧 Feed 再创建。日历只包含所需的标题和时间，不导出笔记或附件正文。

第三方账号连接、Webhook、通用 API Token 和自动化规则尚未提供。

## 离线同步与冲突

入口：**同步与设备**（`/app/sync`）。

### 日常同步

1. 先在联网状态下登录、选择空间并完成必要数据加载。
2. 解锁 Vault 后编辑支持离线的内容。
3. 查看 Outbox；待同步表示修改仍保存在本机队列。
4. 恢复联网后执行同步，检查队列、最后同步状态和附件结果。
5. 换设备前确认需要的记录已同步。

新知识空间接口不自动进入旧同步协议；页面显示在线限定时，应联网操作。设备撤销可以停止新的服务端访问，但无法远程擦除离线设备已经保存的数据。

### 处理冲突

1. 打开冲突，比较本地与服务端内容。
2. 根据页面提供的选项保留本地、采用远端，或编辑合并结果。
3. 不确定时暂不处理，先保留两边需要的内容。
4. 提交解决决定并同步，核对最终记录。

权限、删除、层级和验收冲突不能靠重复同步静默覆盖。旧客户端遇到不支持的删除能力时，先升级客户端再处理暂停项，不要清空原队列。

## 账户安全与数据删除

入口：**账户安全**（`/app/security`）、**数据**（`/app/data`）。

- 添加 Passkey 或启用 TOTP，并将一次性恢复码离线保存。
- 定期检查设备会话，撤销不认识或不再使用的设备。
- 密码恢复后使用新密码正常登录，再检查安全通知与设备状态。
- 删除账户前完成同步和必要导出，阅读页面的确认、恢复期限与保留说明。
- 清除浏览器数据、卸载浏览器或重装系统前，确认没有未同步记录。

Vault 口令、恢复码与账号密码用途不同，应分别保管。丢失本机口令时不能保证恢复仍只在本机的加密记录。

## 手机与 PWA

手机浏览器可访问响应式 Web 界面。支持的浏览器可使用“安装应用”或“添加到主屏幕”；入口名称因系统和浏览器不同而异。

PWA 不等同于完整原生应用，也不保证受保护页面离线冷启动。Android/iOS/HarmonyOS 薄壳的构建与签名条件见[移动端说明](mobile/README.md)。

## 常见问题

| 现象                   | 建议操作                                                            |
| ---------------------- | ------------------------------------------------------------------- |
| 找不到某个入口         | 检查当前画像；通过设置、命令面板或功能总览中的地址打开              |
| 页面提示本地资料锁定   | 解锁 Vault；登录账号不能替代本机口令                                |
| 列表为空或图表没有数值 | 检查工作区、空间、筛选与同步状态，再确认是否已有真实记录            |
| 按钮不可用             | 阅读权限、联网或功能开关提示；需要时联系管理员                      |
| 提示需要近期认证       | 正常退出/重新登录后回到原操作；单纯刷新不一定有效                   |
| 同步持续失败           | 保存未同步内容，检查网络、设备、冲突和错误编号；不要清空站点数据    |
| 收不到验证或恢复邮件   | 检查垃圾邮箱和地址；由管理员检查邮件配置与投递状态                  |
| Passkey 不可用         | 确认浏览器支持、HTTPS 和正确的 WebAuthn 域名配置                    |
| AI 运行失败            | 检查 Provider、模型能力、路由、预算和错误状态；先排除请求结果不确定 |
| 需要报告问题           | 提供页面、操作步骤、时间和脱敏错误编号；不提供密码、密钥或私人正文  |

更多恢复操作见[运维手册](operations/README.md)；安全漏洞请使用[私密报告渠道](../SECURITY.md)。
