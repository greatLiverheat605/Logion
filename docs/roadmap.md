# 路线图

Logion 面向个人与小组的自托管学习、研究和协作。本页区分近期方向、已实现能力与后续探索，不承诺固定发布日期；完整使用条件见[功能总览](product/PROJECT_FUNCTION_MAP.md)，实际变更见[更新日志](../CHANGELOG.md)。

## 近期重点

- 提高离线恢复、同步冲突处理和数据迁移的可靠性。
- 完善新用户引导、键盘操作、小屏布局与可访问性。
- 持续验证备份恢复、Worker 健康、邮件与发布流程。
- 改进 Markdown、模板、复习和研究证据的使用效率。

## 已实现、按开关启用

- 研究工作台包含 PDF 研读、摘录与原文定位、私人精读笔记、理解测验、问题树、知识网和周计划／回顾。
- Zotero 只读同步与坚果云 PDF 导入、读取使用本人配置的凭据及应用层出站控制。
- 个人访问令牌、人工审阅收件箱、stdio MCP 桥及五份共享 Skills 已实现；Agent 能力由独立开关控制，默认关闭。

上述能力的开发完成不代表生产已经启用；使用条件见[功能总览](product/PROJECT_FUNCTION_MAP.md)。

## 后续探索

- 薄移动壳的签名、分发、实体设备与弱网体验。
- 通用第三方账号连接、Webhook 和自动化规则：须先设计凭据管理、范围授权、审计、调度和撤销。
- 旧客户端与旧同步接口的退役：先完成生产稳定观察与旧客户端请求核对，再单独实施清理。

## 持续遵守的原则

AI 输出保留人工决定；私有内容不自动共享；离线和服务端使用同一权限与同步合同。新增功能先解决真实使用问题，再评估迁移、安全、恢复和维护成本。

不规划计费、套餐或 SaaS 运营后台。功能提议请通过 [GitHub Issues](https://github.com/greatLiverheat605/Logion/issues) 讨论；安全问题使用[私密报告](../SECURITY.md)。
