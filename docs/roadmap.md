# Logion 产品与技术路线图

> 范围：个人及最多 10 人的受邀、自托管学习与研究协作。
>
> 固定边界：不加入计费、定价、套餐、entitlement、公开营销站或 SaaS 运营后台。

## 1. 迭代原则

1. 每个版本先关闭数据安全、同步、恢复和可观测性风险，再增加新入口；
2. 图表、进度和建议只使用真实数据，不制造示例成果；
3. AI 输出始终是可审查草稿，不能自动改变掌握度、验收、权限或正式研究结论；
4. Web/PWA 是权威产品核心，手机端复用现有 HTTPS API 与同步契约，不另建一套数据模型；
5. 三端安装包只从受保护的签名流程产生，签名私钥不进入仓库或构建日志。

## 2. 版本批次

### v0.1.0：封闭生产版

目标是把当前 `0.1.0-rc2` 从预发布提升为个人可长期使用的冻结基线。

- 完成 ICP 备案、页脚备案号和外网多网络复测；
- 完成 24 小时稳定观察、真实学习数据闭环和双设备同步/冲突验收；
- 启用 Windows 异机加密备份、48 小时落后检查和季度恢复演练；
- 完成实体 iPhone、Android 的 PWA、软键盘、触控、弱网和恢复验收；
- 保留旧源码、旧镜像和数据卷，所有门禁通过后再人工发布 `v0.1.0`。

本批次不增加业务功能，不改变 API、权限、同步协议或数据模型。

### v0.1.1：稳定性与可维护性

- 管理员健康页：只展示服务状态、最后备份、同步积压和证书日期，不展示正文或凭据；
- 同步故障诊断：把 Outbox、附件队列、冲突和最后成功时间整理为可执行提示；
- Vault 恢复体验：明确设备、本地口令、同步和导出边界，降低误清站点数据风险；
- 可访问性与手机端细节：键盘路径、焦点、读屏标签、软键盘遮挡和小屏图表；
- 真实数据图表补强：学习投入、计划完成、复习到期、掌握趋势和研究证据覆盖。

### v0.2.0：论文研读与证据工作台

- 论文元数据：以 DOI、标题或公开链接连接 Crossref、OpenAlex 等公开元数据来源；
- PDF 研读：用户合法提供 PDF，支持页码定位、批注、引用摘录和阅读进度；
- 文献关系：把论文、声明、支持证据、反证和不确定性连接到现有研究模块；
- AI 伴读：用户明确选择材料后执行摘要、问题生成、术语解释和证据对照，输出带来源定位的草稿；
- 研究审阅：检查引用完整性、证据强弱、潜在反例和待验证假设，不自动判定论文或结论正确。

接入外部论文平台前必须确认 API 使用条款、速率限制、缓存边界和版权；不抓取付费墙正文，不把
私有 PDF 自动发送给 AI Provider。

### v0.2.1：编辑与模板效率

- Markdown 大纲、分屏预览、引用块、代码块、表格和安全快捷操作；
- 目标、读论文、主动回忆、实验记录和每周复盘模板；
- 命令面板、最近对象和上下文快速创建；
- 模板实例保持独立，升级模板不会静默覆盖用户记录。

### v0.3.0：个人移动端

采用“共享 Web/PWA 核心 + 薄原生壳”，避免维护三套业务实现：

| 平台    | 交付物       | 实现方向                                                     | 发布条件                                   |
| ------- | ------------ | ------------------------------------------------------------ | ------------------------------------------ |
| Android | 签名 APK     | Chrome TWA；Digital Asset Links 绑定正式域名和签名证书       | Android SDK、独立签名 keystore、实体机验收 |
| iOS     | 真机测试构建 | 原生 WKWebView；App-bound domains；无 JavaScript 原生桥      | Mac/Xcode、测试 iPhone，约 7 天后重新安装  |
| 鸿蒙    | 签名 HAP/APP | HarmonyOS 6.x ArkUI Web；无 JavaScript 原生桥，不用 APK 替代 | DevEco Studio、HarmonyOS 签名和实体机      |

首个移动版不增加后台常驻同步，不在安装包中内置账号、Cookie、API 密钥、恢复密钥或 AI Provider
密钥。登录、权限、注册、同步和数据模型继续由现有服务端判定。GitHub Release 只上传通过签名、
哈希、恶意软件扫描和真机测试的包及校验文件；免费 Personal Team 不作为 Ad Hoc 或长期分发方式，
iOS 测试构建只保存到 Draft Release/私有构建产物，设备标识、描述文件和签名材料不得公开。

## 3. 每个版本的统一门禁

- 需求和权限/同步/离线影响评审；
- 威胁模型、日志去敏和密钥边界；
- 单元、集成、契约、浏览器和真机测试；
- 数据迁移前向/回退或明确无迁移；
- 加密备份、隔离恢复和回滚步骤；
- `pnpm ci:fast`、浏览器套件和候选安全门禁全绿；
- 独立 Pull Request 审查；Production 和 GitHub Release 由人工明确批准。

## 4. 已确认的移动端输入

已确认应用标识 `work.logion.app`，并具备 Mac、测试 iPhone、真实 Android 手机和 HarmonyOS 6.x
华为设备。iOS 使用免费 Apple Personal Team，只做 Xcode 真机安装；测试构建只进入 Draft Release/
私有构建产物。免费签名通常约 7 天后失效，不承诺 Ad Hoc 分发或长期可安装 IPA。

生产实现不使用 Capacitor 远程 URL。Android、iOS 和鸿蒙壳均不得注册通用 JavaScript 消息桥；系统
分享、通知或文件选择必须在后续版本中逐项完成威胁建模和权限审查后加入。
