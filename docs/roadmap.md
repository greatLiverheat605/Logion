# 路线图

Logion 面向个人与小组的自托管学习、研究和协作。以下是后续关注方向，不是已经交付的功能或固定发布日期；已实现能力见[功能总览](product/PROJECT_FUNCTION_MAP.md)，实际变更见[更新日志](../CHANGELOG.md)。

## 近期重点

- 提高离线恢复、同步冲突处理和数据迁移的可靠性。
- 完善新用户引导、键盘操作、小屏布局与可访问性。
- 持续验证备份恢复、Worker 健康、邮件与发布流程。
- 改进 Markdown、模板、复习和研究证据的使用效率。

## 后续探索

- PDF 研读、摘录定位与更清晰的声明—证据关系。
- 薄移动壳的签名、分发、实体设备与弱网体验。
- 第三方连接和自动化：须先设计凭据管理、范围授权、审计、调度和撤销。

## 持续遵守的原则

AI 输出保留人工决定；私有内容不自动共享；离线和服务端使用同一权限与同步合同。新增功能先解决真实使用问题，再评估迁移、安全、恢复和维护成本。

不规划计费、套餐或 SaaS 运营后台。功能提议请通过 [GitHub Issues](https://github.com/greatLiverheat605/Logion/issues) 讨论；安全问题使用[私密报告](../SECURITY.md)。
