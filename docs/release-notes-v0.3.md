# v0.3 发布说明

状态：候选准备，尚未上线。最终候选版本为 `0.3.0-rc1`，须在 V1–V3 合入且开关保持关闭后的最终 main 上完成 Main → capacity → Nightly → Release 四道同 SHA 门禁。本文不替代候选 manifest 或所有者上线批准。

## 阅读闭环

新在线工作台提供文献库、PDF 阅读、划选摘录与 AI 辅助、五角度精读笔记、理解测验和本人掌握确认。Zotero 单向只读同步；本地 PDF 存入本人坚果云；服务器仅保留加密缓存。AI 笔记、题目和连线进入草稿或建议，正式接受与掌握确认均由本人操作。

研究问题树、私人知识连线和周回顾把阅读组织到研究问题与下周计划中。想法及其连线永不进入 AI；共享空间里的私人研究资料仍按本人隔离。

## 日常界面

今日、计划、记录、统一复习、搜索与设置均接入新外壳。旧笔记在线 Yjs 编辑；旧知识点、回忆题与私人阅读测验在同页复习。设置提供 AI 服务商与路由、设备会话、空间归档和恢复、研究导出、文献集成、审计与通知。手机单栏可完成测验与复习，知识网只读。

新版需要联网，不在 IndexedDB 保存业务副本，也不使用 Service Worker。旧入口先检查本机待同步队列；非空时保留旧同步入口，本机旧数据只在本人明确确认后清除。冻结模块与旧同步协议继续保留，本次不执行 V4 清理。

## 升级与兼容

研究开关默认关闭；现有 keyring、数据卷、旧客户端和旧格式导出保留。所有新增迁移为加法，存在用户数据时拒绝降级。软删除空间持续可恢复，没有自动清理期限；账户删除仍使用其独立政策。

未修补的 v0.2.x 不可直接在升级后数据库运行。回滚 A 使用专门的隐私兼容补丁和四镜像证据，期间暂停账户物理清理，研究队列留待前向版本；方案 B 只做前向修复。两者都不降低数据库版本。操作步骤见 [v0.3 发布与回滚](../infra/runbooks/v03-release.md)，演练见 [迁移演练](../infra/runbooks/v03-migration-rehearsal.md)。

## 验收限制

真实三篇论文、真实模型比较、真实 Safari、生产备份副本演练、Claude 统一审核与所有者验收分别记录；自动化通过不能替代这些未运行项目。参考硬件 capacity 不代表生产等价容量批准。PDF 扫描件不提供 OCR；研究导出不含原始 PDF，当前不支持将 v0.3 导出包重新导入。

完整使用流程见 [用户手册](user-guide.md#v03-一篇论文的完整流程)。V1–V3 即使已开发进 main，仍保持独立开关关闭，留待 v0.3 上线后另行发布。
