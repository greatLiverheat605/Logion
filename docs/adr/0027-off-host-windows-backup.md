# ADR-0027：Windows 异机加密备份

- 状态：Accepted
- 日期：2026-07-30
- 决策人：Logion project owner
- 补充：ADR-0005 的异地备份落地方式

## 背景

Logion 面向个人及最多 10 人的低频自托管。项目所有者决定不使用 OSS；服务器本机 Docker 卷又
不能覆盖系统盘损坏、误删除或实例不可用。因此必须在不引入云对象存储和长期云凭据的情况下保留
异机副本。

## 决策

Backup 服务继续在服务器生成包含 PostgreSQL、附件和版本元数据的 AES-256-GCM 加密 bundle，
并生成 SHA-256 sidecar。Windows 受控电脑每天通过专用 SSH 密钥拉取最新密文到
`F:\LogionBackups`，下载后重新计算 SHA-256；默认保留最近 30 份。

恢复密钥独立保存在 `F:\LogionRecoveryKey\backup.key`，不得上传到服务器备份目录、仓库或公共
同步服务。Windows 任务仅在用户已登录时运行，错过时下次开机补跑；48 小时没有新异机副本视为
告警，季度隔离恢复演练仍是 Production 门禁。

## 后果

- 不再要求 OSS、对象存储或对应 RAM 权限；
- 电脑关机、磁盘离线或公网 IP 变化会导致同步延迟，需人工检查；
- 单台 Windows 电脑仍不是高可用灾备，适合当前小规模边界，不代表企业级容灾；
- 移动端、Web 或 API 不获得恢复密钥，也不承担服务器备份职责；
- 如未来改变备份介质，必须新增 ADR，不在脚本中静默加入第三方上传。
