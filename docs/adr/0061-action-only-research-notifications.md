# ADR-0061：新外壳通知只统计待处理未读

- 状态：Accepted（所有者 R4-9 授权，Claude 统一复核待执行）
- 日期：2026-09-29
- 关联：ADR-0045

## 决定

新外壳和设置页复用已有通知读取与标为已读 API、权限、收件人过滤和最近 200 条上限。
不增加数据表、API schema 或依赖，不改变旧 `/app/*` 通知中心。查询按工作区隔离，共用
已有 QueryClient；页面和顶栏复用一个请求，不写本机存储，不注册 Service Worker。
没有使用中的空间时仍能查看工作区通知。

只有已有服务端生产者中需要用户查看或处理的未读消息计数：安全提醒、到期复习、AI 草稿
就绪、导出下载，以及推送回执中未处理冲突或未接收项非零的消息。普通推送／拉取成功、
成功解决冲突和只读分享创建留在历史中，不计数、不弹卡片。未知通知仍显示历史，不推断
未知动作。同步计数匹配现有服务端固定格式，新增生产者时必须同时更新投影与测试。

这是通知的查看状态，不是源任务的实时完成状态。标为已读不会接受草稿、确认掌握或处理
冲突；页面明确说明，原操作仍通过各自的权限和确认流程。读取失败保留当前工作区最近
成功的历史并提供手动刷新；写入失败不乐观减少未读，也不在恢复联网后自动重放。
已读响应只更新它所属工作区的缓存，切换范围不显示前一个范围的记录。
确认已读后取消该范围仍在途的旧读取，防止较早的快照覆盖已确认状态；同步异常链接
显式携带消息所属工作区，沿用受保护的旧同步入口。

已知旧服务端英文回执在新界面显示中文，普通保存继续使用原有行内状态。顶栏使用有
上下文的可访问名称；页面用单一完整状态句报告未读数量，避免只有数字的读屏播报。

## 验证

单元用例区分普通成功、已解决冲突、未接收项、待处理冲突、已读和未知类型。真实后端
导出 Worker 产生消息后，浏览器验证单次首屏请求、中文、显式已读、断网失败、恢复不
重放、读取失败保留记录、四宽双主题、键盘、44px 控件、axe 与无本机存储。
