# ADR-0058：研究搜索、权限与分页

- 状态：采纳
- 日期：2026-09-29

## 决策

在默认关闭的研究开关下新增 Space 范围搜索。检索本人的文献元数据、当前文件的全文、有效摘录，以及有权读取的旧知识点、私人概念和回忆题。每次请求先检查空间权限，SQL 同时检查行归属与父文献、父知识点；删除或撤权后不可继续读取。全文旧文件版本与失效摘录不参与。想法和连线不在查询表中；搜索不调用 AI、不写数据库、不搜索题目答案或解释。

使用 PostgreSQL NFC 规范化、大小写不敏感的字面子串匹配，百分号、下划线和反斜线没有通配含义。查询为 2–120 个可打印字符，每页最多 50 条，摘要最多 240 字符；不回传整份全文。按类型与 ID 稳定排序，通过已有 KnowledgeCursorCodec 签名并绑定本人、工作区、空间、查询、类型和页大小。沿用游标密钥与轮换配置、15 分钟有效期、读取限流和 500 毫秒查询上限；未配置游标签名时明确拒绝搜索，不使用未签名降级。游标记录首次查询时刻，后续新增或修改的条目须重新搜索才出现；不承诺跨请求数据库快照。

搜索页与指令面板共享 React Query 请求身份，在 30 秒新鲜窗口内复用结果，传播取消信号，按当前身份和空间隔离缓存。搜索不触碰 IndexedDB 或 Service Worker。文献、全文与摘录回到阅读器；全文定位到首个匹配页，摘录保留来源页码。旧知识点和回忆题回到复习页，私人阅读题回到原文测验。私人概念通过同权限、只读详情展示，避免链接到不支持私人概念的旧复习接口。

## 兼容与代价

只新增 API paths/schemas，不修改旧搜索、旧知识网或复习合同；没有迁移或新增依赖。复用 LOGION_KNOWLEDGE_CURSOR_ACTIVE_KEY_ID / LOGION_KNOWLEDGE_CURSOR_KEYS 等配置，研究搜索启用前必须配置。普通规模采用有界子串查询；超出查询时限返回明确错误，维护者再根据实测评估索引，不能静默省略某类结果。服务器响应 private, no-store；浏览器只在当前会话内短时共享查询结果，结果页导航重新检查访问权限。

## 验证

合成真实后端覆盖五类检索、分页篡改、共享空间私人隔离、删除父级、撤权、关旗、Unicode 与字面匹配、答案和想法哨兵。浏览器覆盖指令与页面请求复用、原文定位、复习导航、键盘、四宽双主题、无离线存储。
