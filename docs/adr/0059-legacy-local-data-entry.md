# ADR-0059：旧队列检查与本人确认的本机清理

- 状态：Accepted（所有者 R4-8 授权；统一独立复核仍待 Claude）
- 日期：2026-09-29
- 关联：ADR-0038、ADR-0046

## 路由与读取边界

研究开关开启后，旧 `/app/*` 页面 GET 临时重定向至已认证的旧数据检查页。
旧页面逻辑、非 GET 请求及 `/app/api/*` 保持；开关关闭时旧入口保持原行为，新增页面返回 404。
检查页使用新外壳和会话门，不加载旧 Vault。仅本人主动选择的 `/app/sync?legacy=sync`
保留旧同步入口；该选择设置仅限 `/app/sync` 的 HttpOnly、SameSite=Strict 会话 Cookie（HTTPS 时 Secure），
让旧同步页不带标记的既有分页／冲突链接继续工作。该标记只保存本人选择，不证明队列为空，
不放行其他旧页面，也不绕过同步页原有认证、入门、解锁或权限。
目的地来自固定映射，丢弃旧查询参数；未知或冻结模块回到今日，不接受任意返回 URL。

账户 ID 只来自当前已认证会话，校验 UUID 后定位 `logion-offline-v1-<user-id>`。
原生 IndexedDB 无版本参数打开，仅用 `readonly` 事务读取 `outbox.count()`，不读取条目、
密文、附件或 Vault，不调用 Dexie 升级路径。不存在数据库时中止新建事务并返回零；
权限拒绝、存储不可用、缺少 store、事务失败或阻塞均显示错误，不能伪装为空队列。
计数完成立即关闭连接；零条完整导航到映射的新页面，非零显示数量、旧同步链接和重新检查。
不保存“检查通过”Cookie，也不自动清队列；其他标签页的后续修改仍可能改变数量。

## 明确确认的清理

设置中的清理页说明当前账户、当前浏览器范围，以及未同步内容、附件和草稿永久丢失的后果。
打开对话框默认聚焦取消，必须勾选理解损失并再次确认。真正删除前重新读取服务器会话并比对
账户，失效或更换账户时拒绝操作。只删除精确匹配的单个旧数据库；不枚举后批量删除、
不清 Cookie、不动其他账户或服务器数据。检查页本身没有自动清理动作。

IndexedDB 删除被其他连接阻塞时，请求仍待完成且无法取消。界面保持处理中，说明关闭其他
标签页后会继续已确认的删除；禁止重复提交并阻止普通页面离开，不误报成功或留下“失败但
后台仍会删除”的隐藏请求。只有 `onsuccess` 才显示完成；错误继续保留在确认框。
队列为空不代表附件、冲突或本机草稿均有备份，清理说明明确要求先核对需要保留的内容。

## 安全审查与验证

这是 R4-8 明确授权的存储例外，其他新页面仍不写 IndexedDB，也不注册 Service Worker。
没有新依赖、API 或迁移，不改变 CSRF、Origin、会话或后端权限。存储访问仅发生在两个专用页。
自动化只操作随机合成账户的浏览器库：覆盖无库不新建、只计数不解密、跨账户隔离、存储异常、
取消、账户变化拒绝、阻塞期间不报成功及最终清理；路由测试覆盖开关、固定目的地与旧同步入口。
当前执行方负责上述边界复核；测试结果记录在 PR 与 CI artifacts，不将待运行项宣称通过。
