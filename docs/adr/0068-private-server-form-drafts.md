# ADR-0068：私人服务端表单草稿

- 状态：Accepted；落实已批准 ADR-0038，所有者要求按现有规划补齐遗漏并验收。
- 日期：2026-10-04
- 关联：ADR-0038、ADR-0063、ADR-0067。

## 决定

新版非凭据长文本表单使用 `form_drafts`，按本人、Workspace、Space、表单种类和目标对象隔离。
涵盖文献作者/摘要、想法正文、研究问题/缘由/拆分文本、目标说明/成果/验收、阶段说明/验收、
知识点说明、回忆题题目/答案/解析、测验作答、周回顾分诊理由、连线理由和引用提问。
笔记、精读笔记继续使用既有 Yjs 自动保存；旧客户端保留 ADR-0034 的加密本机草稿。

停止输入约 2 秒后自动保存。只有服务器确认后才显示已保存；断网不排队、不自动重试，
失败保留本页输入。恢复需本人选择，不静默覆盖；只恢复长文本和关联它所需的结构标识，
标题、日期、目标选择、处理动作及危险确认等其他字段需要重新确认。
每人最多 20 份、每份最多 4 MiB，字段各有更小上限；每次保存起保留 7 天。
读取不返回过期正文；Worker 有界清理到期行，创建时清理本人的到期行再核对配额。

草稿 ID 与版本共同保护更新和丢弃，避免删除重建后版本号重用导致旧标签覆盖新内容。
发生冲突时暂停自动写入，重新读取后由本人选择恢复远端或保留本页长文本。
提交等待在途保存完成，携带可选 `X-Logion-Form-Draft` 引用；服务端核对本人、范围、表单、
目标、ID、版本与期限，并在正式业务成功提交的同一事务中删除草稿。业务失败保留草稿。
已有客户端省略该引用时继续执行原合同。

## 安全与生命周期

草稿接口复用研究开关、会话、Origin、CSRF、写入限流及 Space/对象权限。表单字段白名单
排除密码、验证码、API Key、凭据和任意未登记字段。数据只在当前页面内存和服务器中，
不写入浏览器持久存储、查询缓存或离线队列。

草稿不注册到 AI、Agent/MCP、搜索、同步、业务导出或共享实体读取。只有本人明确提交后的
正式业务对象按原有规则使用；引用提问与测验仍由本人触发既有 AI 发送流程。
草稿审计仅记录表单种类，不记录正文、目标对象或草稿标识。

显式退出登录在撤销会话的同一事务中删除本人全部草稿。草稿写入与退出按同一用户锁串行化，
取得锁后重新检查会话，防止已认证的迟到请求重新写回；账户物理清理同样删除草稿。
空间归档、删除或撤权立即拒绝访问，保留行按到期策略清理，不转移给其他成员。

## 迁移与回滚

`0058_form_drafts` 为加法迁移，接在 `0057_session_persistence` 后，不改既有业务数据。
存在草稿时拒绝 downgrade；ADR-0038 中“可删除草稿表”的早期简述不能当作生产删数据授权。
回滚 A 必须重新绑定并验证这一 schema，保留会话持久性选择及退出清理；旧应用不提供草稿
读取入口，旧 Worker 继续有界清理到期草稿。原 0056 候选的兼容证据只证明其历史 schema，
不能复用于新迁移。

## 验证要求

验证本人/同伴/空间/撤权隔离、字段上限和配额、七天边界、丢弃重建后的旧版本拒绝、
成功提交原子清理、失败保留、退出竞态，以及搜索/同步/导出/AI/Agent 哨兵排除。
真实浏览器验证显式恢复、多标签冲突、离线保留、提交和退出清理，并运行现有表单旅程。
