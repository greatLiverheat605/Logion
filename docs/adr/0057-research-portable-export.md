# ADR 0057: v0.3 研究导出使用独立格式与双时点权限检查

- 状态：Accepted
- 日期：2026-09-29
- 范围：R4 设置／数据导出；依据所有者施工说明、ADR-0019、ADR-0041

## 决策

新增 `logion-export-v03`，通过 `/api/v1/workspaces/{workspace_id}/research/data-exports`
创建、列表、下载和取消。旧路径、响应 schema 和 `logion-export-v1` 序列化保持兼容。
新路径及后台生成受默认关闭的研究开关控制；旧路径不能下载或取消研究格式任务，同一任务 ID
不能跨格式复用。现有 `DataExportJob.schema_version` 足够区分格式，无迁移、无新依赖。

沿用后台队列、独立 AES-256-GCM keyring、绑定工作区／任务／密钥 ID 的 AAD、明文产物
SHA-256 校验和创建后 24 小时有效期。密文只保存在服务器，认证下载提供可读 ZIP，不是
密码加密 ZIP。创建和取消继续检查 Origin、CSRF、最近认证与原有工作区／用户限流；
下载仍要求最近认证，返回 attachment、private no-store、nosniff、no-referrer。

## 格式与数据边界

ZIP 包含 `manifest.json`、`data.json`、`notes.md`、`tasks.csv` 和 `papers.bib`。
manifest 记录格式、导出时间、工作区、空间 ID、各表数量和排除项。`data.json.objects`
使用明确的表及字段白名单，不复制 ORM 的全部列：

- 可访问空间内的目标、计划、版本和阶段，以及授权任务和学习记录；
- 文献的 CSL／DOI／arXiv／PMID／Zotero 定位、阅读状态和文件元数据；
- 已提取的规范化全文及逐页偏移、摘录和定位、普通／精读笔记的 Markdown；
- 知识点、先修关系、来源关联和知识引用；
- 本人的问题、论断、想法、测验作答、AI 批改证据、掌握与复习计划；
- 本人的所有状态连线（包括被拒绝建议）及周回顾快照／处理决定／已接受点评；
- 可导出文献、笔记和任务对应的附件元数据，排除对象存储定位。

兼容旧共享笔记、知识点与任务；私人研究实体必须满足 `research_owner_id` 或 `user_id`
等于请求者。关联表只能引用已导出的授权端点。停用题目若有本人保留的作答，也保留题干、
参考答案和删除时间；其他已软删除实体不进入正文。已有学习历史会阻止知识点删除。
本人笔记、任务与连线仍保留不可用来源的 ID，不因来源不可用丢掉本人记录；这类 ID 是历史
引用，不保证目标正文在包中。研究来源及个人历史不借旧格式的关联表隐式扩展。

不包含凭据、会话、恢复资料、AI 原始输入、内部 Yjs 状态、PDF 或附件二进制。
想法及其连线仅作为本人下载数据，整个流程不调用 AI 或上下文构造器。旧冻结模块的完整
数据仍通过旧格式导出；新格式不提供导入适配器，界面不暗示可以恢复原始 ID 或权限。
BibTeX 提供文献标题、作者、年份、刊物和标识符，JSON 保留完整白名单字段。

## 权限与并发安全审查

生成时要求用户有效且已验证、工作区有效、成员关系有效；可访问空间包含归档空间，排除
已删除空间和其他成员私人空间。按 User → Workspace → Space（UUID 排序）获取共享锁，
随后查询数据；与账户删除的 User 首锁、成员变更的 Workspace 首锁保持兼容。
生成不锁成员行；完成时才锁任务，取消只锁任务，不形成反向等待。

下载解密并验证摘要后重新验证用户、工作区、成员和 manifest 中的全部空间。空间已删除、
变为不可访问或成员关系撤回时拒绝下载，要求按当前权限重新生成。权限检查锁保留至请求
事务结束。正文沿用时点快照语义，生成后的正文编辑不改旧包；不承诺全库历史恢复。
大批 ID 过滤使用一个 PostgreSQL UUID array 参数，避免库规模增长触发参数数量上限。
归档恢复与删除保留期限由空间生命周期另行定义，本决定不物理删除或改变用户数据。

## 验证要求

真实数据库验证新旧格式、共享成员哨兵、加密存储、摘要／到期、生成与下载的撤权、关旗
和跨格式访问、Origin／CSRF／最近认证。真实 Web／API／Worker 验证创建、等待、下载及
ZIP 内容；四宽明暗主题、键盘确认、无溢出与无离线存储。下载复用现有 Blob 生命周期组件，
新增研究路径选项默认关闭，旧页面行为保持。
