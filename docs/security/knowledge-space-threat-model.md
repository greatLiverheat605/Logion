# 自适应知识空间威胁模型

- 状态：v0.2.0 Proposed 设计基线；尚未授权实现或上线
- 范围：来源元数据、SourceExcerpt、KnowledgeCitation、图查询、AI 候选/接受、附件绑定和可中断本地知识 Worker
- 依赖：ADR-0002、ADR-0003、ADR-0004、ADR-0013、ADR-0015、ADR-0016、ADR-0021、ADR-0029

## 资产与安全目标

- 私有来源元数据、摘录正文、定位、Prompt/模型响应、草稿、正式知识、研究声明和复习状态；
- Workspace/Space/个人所有权、会话、命名 permission、乐观版本及用户接受意图；
- 来源/内容哈希、typed citation、处理器/Prompt 版本、幂等收据和最小审计证据；
- Provider 凭据、预算账本、外部请求状态、本地租约、检查点和加密工作区；
- 服务可用性、配额、公平调度、图/检索延迟、备份和删除证明。

目标是机密性、租户隔离、引用真实性、接受的新鲜性、正式知识完整性、可追溯性、可删除性及核心学习流程可用。哈希证明内容一致，不证明内容真实、版权、授权或学术正确。

## 信任边界与参与者

1. 浏览器/移动壳 ↔ API：客户端、版本、ID、HTML、哈希和权限声明均不可信；Cookie 认证、Origin/CSRF 和服务端授权是边界。
2. API ↔ PostgreSQL/Redis/附件存储：数据库约束是范围与幂等权威；缓存、索引和对象存储不能扩大权限。
3. API/Worker ↔ AI Gateway ↔ 外部 Provider：模型、结构化输出、计费结果和网络完成状态不可信；Provider 凭据只在服务端边界。
4. 云端 ↔ Windows 本地 Worker：远端任务、租约、本地文件、检查点和上传结果互不默认信任；仅出站 HTTPS、短期租约和内容验证。
5. 私有 Space ↔ Shared Space：是数据披露边界，不是普通字段更新。
6. online-only 知识 ↔ sync-v1/Vault：v0.2.0 新实体不得穿越该边界；缓存不是权威离线副本。
7. 正式知识 ↔ Draft/Suggested：只有经重新授权和版本校验的接受事务可跨越。

参与者包括合法 owner/editor/contributor/reviewer/viewer、被撤权或会话被盗用户、恶意 Workspace 管理员、跨租户攻击者、恶意文件/来源作者、提示注入内容、错误或对抗 Provider、重复投递 Worker、拥有数据库/日志/备份访问的内部人员，以及无意误分享或接受陈旧建议的用户。

## 隐私、保留与租户隔离要求

- 数据最小化按“每次运行”执行，不以用户曾授权某文档推定永久授权。预览与实际发送字段必须可核对。
- 摘录可能包含个人信息、受版权保护材料、考试内容或第三方秘密。产品需显示存储/发送目的、Provider、保留策略、删除影响和共享影响；不得声称哈希实现匿名化。
- Private Space 正文不因 Workspace 管理角色开放。搜索索引、缓存、图聚类、导出、备份、通知、AI 和 Worker 使用相同 scope。
- 日志/审计保留最小元数据；正文、Prompt、响应、完整哈希、文件名和来源查询不进入可运维搜索面。
- 私有清理、共享团队记录、审计、Provider 保留和备份自然过期需要版本化政策与法律/隐私批准。未批准前不得承诺具体生产删除期限。

## 残余风险

- 用户可以批准错误、偏见或伪造的来源；人工接受降低自动写入风险，不证明事实正确。
- 拥有应用解密能力、活动数据库权限或已解锁本地设备的受控进程仍可能读取正文；需要运维隔离和设备安全持续控制。
- 外部 Provider 可能保留或滥用已授权数据，其法律条款和真实 API 行为必须在启用前逐一评估。
- 没有恶意软件扫描/CDR 时，白名单文件仍可能含恶意载荷；首版只能下载而不执行/内联，并如实披露。
- 哈希和精确摘录可能用于关联已知文档；它们不是匿名标识。
- 超大或稠密图即使有界仍可能造成成本尖峰；Beta 容量停止线触发时应暂停摄入而非放宽限制。
- sync-v2、语义检索、完整 PDF 云处理和本地 Worker 远程执行协议尚未设计，不能由本威胁模型推定安全。

## 上线前安全停止条件

- typed target 无数据库级恰好一个目标或范围 FK；
- 存在 AI/Worker 绕过接受事务的正式写路径；
- stale/并发接受、跨租户、重放/重复计费或日志脱敏负测未通过；
- sync-v1 合同或 golden vectors 出现计划外变化；
- 删除/恢复无法证明引用闭包，或保留政策未获批准；
- 本地 Worker 所在卷/工作区未证明静态加密，或需要仓库/任务包中的秘密；
- 迁移不可降级、OpenAPI 未审查、附件能内联执行，或图查询没有服务端硬上限。
