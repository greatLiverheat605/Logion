# v0.3 所有者本机验收（175 分钟）

本脚本在 Claude 统一审核后由所有者亲自执行，目标是核对最终候选上的完整阅读与研究体验。
只在本机隔离栈运行，不连接生产数据库、数据卷、Redis 或备份。临时 Key 由所有者自行提供，
不要交给开发 Agent、粘贴到对话、提交源码或出现在截图/终端记录中。自动化通过不能代替本页签字。

## 开始前（不计人工验收时间的构建准备）

依据最终总完成包固定 main 完整 SHA 和四镜像 digest，按 [开发指南](../../docs/development/README.md)
准备专用本机 PostgreSQL、Redis、附件目录和浏览器资料目录。仅绑定回环地址，数据库、卷与 Compose
project name 使用单独的验收名称；不得复用现有生产配置。准备两名合成测试账户及一个共享空间。
用该候选的新 API 执行 `alembic upgrade head`、`alembic heads`，应只有 `0058_form_drafts`。
没有可用栈或 Claude 仍有未解决的问题时，记录“未运行”，不要消耗三小时排环境后再声称验收通过。

准备三篇所有者有权使用且熟悉内容的真实论文 A/B/C，以及其 PDF。至少 A 经 Zotero 同步、C 经本地导入；
先在本人 Zotero 客户端完成附件 WebDAV 同步。使用专用临时 Zotero 个人库只读 Key、专用 WebDAV 应用密码、
有限额的临时模型 Key；不改变 Zotero 源数据。WebDAV 验收会新增 `Logion/<sha256>.pdf`，保留此次使用的专用空间。
服务器使用各自独立的集成、PDF 缓存、搜索签名 keyring，API/Worker 配置见
[文献集成](../../docs/operations/research-integrations.md)。密钥在运行环境注入，不写入覆盖文件。

真实论文验收使用正常应用启动器；不要使用注入假 AI 的 `tests/fixtures/research_runtime.py`。
Zotero/WebDAV 使用默认 HTTPS 主机，不配置本地假服务覆盖。模型出站仅批准实际服务主机，保留 TLS、
白名单、Origin、CSRF 与预算闸门。先只开研究与计划修订开关，Agent 开关到第 5 段才在该本机栈开启。

在忽略目录自行记录每项：候选 SHA、开始/结束时间、通过/失败/未运行、脱敏截图名与问题描述。
真实论文正文、账户信息和凭据不进入公开交付包；失败不自动重试覆盖，修复后另记一轮。

## 1. 连接与旧数据入口（0–15 分钟）

登录合成账户，日间/夜间切换并刷新，确认首屏采用已保存外观。在新设置页配置 Zotero、坚果云和模型，
测试连接，检查响应只显示状态、最近同步与错误码。配置经济/高质量路由、可用模型和小额预算。
先不显示或录制凭据界面，保存后再截图。

从专用浏览器打开旧 `/app/*`：队列为零进入新版；有合成未同步队列时显示旧数据检查与同步入口。
只用合成本机数据验证清理的取消与明确确认。实际仍使用设备的同步检查按
[切换手册 §3](v03-release.md)逐一记录，不能用本机队列为零替代。

## 2. 三篇真实论文闭环（15–81 分钟，每篇 22 分钟）

对 A、B、C 各执行完整步骤；至少一次拖入多个 PDF 或文件夹，并重复导入验证按哈希去重。

1. 导入/同步后核对标题、作者、标识符与 Zotero 集合标签；同步的条目和批注只读。
2. 打开 PDF，连续滚动、缩放、页内查找、大纲与缩略图；抽取全文后刷新仍可定位原页。
3. 在文字层选择一段，依次做 T 翻译、E 解释、H 摘录、Q 引用提问、C 概念引用；核对页码/偏移及回到原文。
   输入框内或没有 PDF 选区时单键不触发，指令面板同样可用；关闭划选菜单后浮层不出现。
4. 按动机、建模、实验、结论、批判、一句话要点、待解决问题填写笔记。只让 AI 起草缺失节，
   检查草稿未接受前正式笔记不变；接受后自动保存，刷新及另一标签页仍可读。
5. AI 生成默认 5 题；先看到草稿，本人接受后逐题作答并批改。核对得分、证据与薄弱概念。
   批改后不能自行变为掌握；本人确认掌握后进入复习，复习中的后续判断仍可修正。
6. 阅读状态从未读到在读到精读完成；文献库筛选有效，今日页可继续阅读。至少一篇在 390px 下完成测验与复习。

三篇都必须走完；遇到真实服务不可用则记为未完成，而不是用假服务结果补齐。

## 3. 模型对比与故障提示（81–96 分钟）

由所有者在自己的父进程环境中临时提供 `LOGION_COMPARE_DEEPSEEK_KEY/BASE_URL/MODEL`
和 `LOGION_COMPARE_GLM_KEY/BASE_URL/MODEL`，不在命令行中写值，然后执行：

```bash
uv run --package logion-api python scripts/compare-research-models.py
```

脚本只向两类配置模型发送三段合成材料，共 6 次有界调用；不会读取论文或想法。
看 `.local/ai-comparison/` 的证据忠实度、局限说明、耗时与用量，手工选择路由，不自动宣布胜者。
再比较 A 的同一段文字在两个路由的实际翻译/解释，原文引用和符号必须一致；限制新增调用预算。
在合成账户把预算调低，验证不足时有明确提示；恢复原测试预算。配置一个不可用的合成模型标识，
验证服务不可用时提示且保留输入，再恢复。运行后移除临时环境变量，不保存 Key。

## 4. 知识网、周回顾与新版页面（96–141 分钟）

- 建立一个研究问题及子问题，核对拆分/合并。用论文与问题请求建议连线，确认一条、拒绝一条，再请求时被拒绝关系不能复活。
- 手动创建带合成哨兵文字的私人想法和想法连线，界面标注“仅自己可见，AI 不可读”；共享空间的另一成员看不到它们。不要把真实未公开想法放进任何 AI 请求。
- 建立周阅读计划，至少准备顺延、降级、放弃三种未完成项；每项选定后确认周回顾，再核对下周计划。AI 点评只根据统计数字。
- 今日核对到期复习、阅读计划、继续阅读；计划修改目标/阶段，记录编辑旧 Yjs 笔记并刷新；复习覆盖旧知识点、回忆题与私人论文测验，并回到原文。
- 搜索文献、全文、摘录、知识点和回忆题，试用 ⌘/Ctrl+K；想法不参与搜索或 Agent 读取。
- 设置核对模型与路由、审计、通知、设备；确认“退出其他会话”只退出其他设备，当前会话继续；正常退出后设备识别保持。
- 登录分别检查未勾选和勾选“保持登录”的 Cookie 持久性，刷新不改变选择；公共电脑主动退出。
- 长文本输入后等待草稿已保存，刷新并显式恢复；另一标签修改时检查冲突提示，断网不得误报已保存。
  提交成功后草稿清除，失败保留；退出清除本人草稿，同空间另一成员不得读取或导出草稿正文。
- 仅对合成空间检查归档恢复、删除前导出提示、二次确认与持续恢复。取消不改变数据；恢复先归档，子对象不自动复活。
- 导出研究 ZIP，核对本人文献、全文、摘录、笔记、想法、测验/作答、连线与周回顾；不得包含另一成员私有记录。
- 依次在 320、390、1024、1440 宽度、日间/夜间检查导航、阅读器、表单与手机底栏，无重叠/截断/横向溢出；Tab/Enter/Escape 可操作。

## 5. V1–V3 Agent 收件箱（141–165 分钟）

仅在当前隔离栈设置 `LOGION_AGENT_API_ENABLED=true` 并重启 API；不改变生产开关或研究数据。
按 [MCP 桥安装](../../packages/mcp-bridge/README.md) 配置本机客户端，令牌只通过环境变量传递。

1. 在 Agent 设置创建绑定当前空间、有期限的 read + inbox:write 令牌；复制后关闭，刷新不能再取明文。
2. 经 MCP 检索论文并读取摘录、问题/概念，提交一条文献；接受前文献库没有该条目。
3. 本人编辑后接受并在文献库核对；再提交一条报告或摘要，接受后打开私人笔记并修改。
   丢弃另一条合成投稿，确认正式记录未增加。助手不能直接接受、删除或修改正式数据。
4. 用同一令牌尝试 `read_context` 的 `research_idea` 类型，必须被拒绝。
5. 撤销令牌，再检索应返回 `AGENT_HTTP_401`；已有投稿与接受记录保留。
6. 运行 Skills 导出，核对 5 个文件与 SHA-256，按 [安装说明](../../packages/skills/README.md) 放入本机客户端目录；
   检查可发现并能按授权材料起草，草稿和掌握确认不会自动落正式数据。

## 6. 结论与收尾（165–175 分钟）

关闭本机 Agent 开关，移除临时进程环境，按所有者选择撤销外部临时凭据。保留隔离数据库、失败记录和
需要的脱敏证据；本脚本不执行数据库降级、不自动删除原文、缓存、WebDAV 文件或设备数据。

填写结果：三篇是否全部闭环、模型比较结论、R3/R4/V1–V3 的失败/未运行项、物理 Safari 是否实测、
Claude findings 是否全部处置。任一必需项未通过则保留“待验收”；本页完成只证明本机候选验收，
生产备份副本演练与生产上线批准仍由所有者另行决定。
